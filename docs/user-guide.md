# 代码重构工具使用指南

## 这是什么

这是一个分析 Python 坏味道并尝试自动修复的命令行工具。

运行后会依次做三件事：
1. 扫描代码 → 2. 规划修复 → 3. 执行修复 + 自动验证

整个过程是一条命令从头执行到尾，中间不停顿。

---

## 怎么运行

```bash
python src/main.py <文件路径|目录路径>
```

支持单个文件或整个目录。工具会自动扫描路径下所有 `.py` 文件。

---

## 它能检测什么

扫描 Python 文件，识别三类坏味道：

| 类型 | 阈值 |
|------|------|
| 过长函数 | 函数体超过 30 行 |
| 过长参数列表 | 参数超过 5 个 |
| 过大类 | 方法超过 10 个，或字段超过 10 个 |

每个检测结果包含位置（文件名:行号）、严重度评分和关键度量值。

---

## 它能修复什么

| 坏味道 | 对应修复 | 当前状态 |
|--------|---------|---------|
| 过长函数 | 提取函数 | ✅ 已实现 |
| 变量名含义不清 | 重命名变量 | ✅ 已实现 |
| 过长参数列表 | （暂无对应修复） | ❌ |
| 过大类 | 提炼类 | ❌ |

检测到但无法修复的坏味道会在规划阶段被跳过，不影响流程。

---

## 安全保证

每次修改后会自动运行 `python -m py_compile` 检查语法。如果编译失败，修改会被撤销。

---

## 能力边界

- 只支持 Python。不处理 TypeScript/JavaScript。
- 只处理同一文件内的重构。不涉及跨文件修改。
- 没有交互式界面。不会停下来等你确认。
- 没有 `--help`、`--dry-run` 等命令行参数。
