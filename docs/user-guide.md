# 代码重构工具使用指南

## 这是什么

这是一个自动分析 Python 代码质量并帮助修复的工具。它能发现代码中的常见问题，规划修复方案，然后直接修改代码。

## 使用流程

### 1. 发现坏味道

工具会扫描 Python 源文件，定位以下三种常见问题：

| 问题类型 | 判断标准 | 例子 |
|---------|---------|------|
| **过长函数** | 函数体超过 30 行 | 一个函数从上到下需要滚动才能看完 |
| **过长参数列表** | 参数超过 5 个 | `def create_user(name, email, phone, address, age, gender)` |
| **过大类** | 方法超过 10 个，或字段超过 10 个 | 一个类既处理订单、又发送邮件、又生成报表 |

每个检测到的问题会附带：
- 在代码中的具体位置（文件、行号）
- 严重程度评分（0 到 1）
- 关键度量值（如行数、参数个数）

### 2. 规划修复方案

检测完成后，工具会为每个问题推荐最合适的重构手法，并按严重程度排序。建议从评分最高的问题开始处理。

### 3. 自动修复

选择要修复的问题后，工具会直接修改代码，无需手动编辑。目前支持以下自动修复：

- **重命名变量**：将含义模糊的变量名（如 `x`、`n`）替换为能表达其用途的名称
- **提取函数**：将长函数中逻辑独立的代码段拆分为单独的函数

每次修复后，工具会自动做两件事来保证安全：
1. **编译检查**：确认修改后的代码能通过 Python 语法解析
2. **语义验证**：对比修改前后的代码，确认行为一致（可选，需要配置 LLM）

如果验证不通过，修改会被自动撤销。

## 运行方式

```bash
python -m src.main
```

工具会扫描示例代码，展示检测结果和执行修复。如需扫描自己的 Python 项目，请将目标文件路径传入 `RefactoringSession`。

## 依赖说明

- 全部功能在标准 Python 环境下可用，无需安装额外依赖
- 语义验证功能可选：配置 `LLM_API_KEY` 环境变量后可启用更智能的代码分析
- 未配置 API Key 时，条件检查自动放行，不影响修复流程

## 目前不支持

- 修改 TypeScript/JavaScript 代码（仅支持阅读和检测）
- 跨文件的代码重构（如将函数从一个文件搬到另一个）
- 自动生成单元测试
- 一键修复所有问题（需要逐条确认）
